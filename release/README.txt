Project Zomboid 42.22 | Single-player public test build

INSTALL (Windows, default Zomboid folder)
1. Close the game. Back up any saves you care about.
2. Install ONE Java runtime: ZombieBuddy 2.3.4 OR KnoxBridge Runtime.
   If you already use one, keep it. Never enable both.
   New to Java mods? Download KnoxBridgeSetup.exe from:
   https://github.com/exe-create/KnoxBridge/releases/tag/v0.1.0-alpha11
   Run it and choose 1 - Install/Update.
   Also subscribe to the separate KnoxBridge Runtime mod and enable it:
   https://steamcommunity.com/sharedfiles/filedetails/?id=3810025624
3. Unsubscribe from the Steam Knox Survivors item if you use it, to avoid
   loading an older copy. Keep your chosen runtime installed.
4. Move any old local KnoxSurvivors folder somewhere safe. Copy the included
   mods folder into %USERPROFILE%\Zomboid (paste this path into File Explorer).
   The final path must be:
   %USERPROFILE%\Zomboid\mods\KnoxSurvivors\42\mod.info
5. Start the game through Steam. Enable Knox Survivors and your chosen runtime
   mod in Mods for a new test save. For KnoxBridge, open Review Java Mods and
   choose Allow selected JAR for Knox Survivors. For ZombieBuddy, choose Allow
   in Java Mod Approval (the module is unsigned). Fully restart if requested.

The Java gameplay JAR is already inside the mod. No building or launcher needed.
This download does not include a Java runtime. 42.21 and multiplayer unsupported.
If it does not load: check the folder path, remove duplicate Knox copies, and
confirm that exactly one runtime is installed and the module was approved.
Report bugs: https://github.com/exe-create/KnoxSurvivors/issues
